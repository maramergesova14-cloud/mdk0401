# МДК.04.01 — Внедрение программы

## Тема: Электронный журнал группы

Я выбрала тему электронного журнала, потому что в нём можно хранить информацию о студентах, предметах, оценках и посещаемости.

## Для чего нужен проект

Цель — сделать учёт оценок и посещаемости удобнее, чем в бумажном журнале. Информация будет храниться в одном месте, и её будет проще найти.

## План работы

Работу можно разделить на несколько этапов:

1. Сначала определить, что должно быть в журнале.
2. Подготовить компьютер и установить нужные программы.
3. Запустить приложение и проверить основные функции.
4. Проверить добавление и изменение студентов, предметов, оценок и посещаемости.
5. Исправить ошибки, если они появятся.
6. Подготовить короткую инструкцию и показать работу преподавателю.

Плановая продолжительность — около 15 рабочих дней. Это примерный план, сроки могут меняться.

## Что понадобится

- Python и Django;
- Django REST Framework;
- база данных SQLite для локальной работы;
- GitHub для хранения проекта.

## Как запустить приложение

Открыть командную строку в папке проекта и выполнить команды:

```bat
venv\Scripts\activate
python manage.py runserver
```

Потом открыть в браузере адрес http://127.0.0.1:8000/. Для работы с API можно открыть адрес http://127.0.0.1:8000/api/. Если адрес главной страницы не открывается, это не обязательно ошибка: в проекте могут быть настроены только адреса API и админки.

## Что проверить

- открывается ли список студентов;
- можно ли добавить студента;
- можно ли открыть список предметов;
- сохраняются ли оценки;
- можно ли записать посещаемость;
- сохраняются ли изменения после обновления страницы.

Проверки нужно выполнить перед сдачей. Здесь указан план проверок, а не утверждение, что все они уже пройдены.

## Возможные проблемы

Могут возникнуть ошибки при запуске, неправильные данные или проблемы с базой. Поэтому перед запуском нужно проверить настройки и сделать копию важных данных. Если что-то не работает, записать ошибку и исправить её.

## Когда работа будет готова

Можно считать внедрение подготовленным, когда приложение запускается, основные функции проверены, данные сохраняются и есть понятная инструкция для пользователя.
