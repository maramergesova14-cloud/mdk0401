# Памятка по запуску и передаче в эксплуатацию

## 1. Перед запуском

1. Уточнить, какая база данных используется в целевой среде.
2. Проверить переменные окружения и не сохранять пароли в Git.
3. Установить зависимости проекта.
4. Применить миграции Django.
5. Проверить доступность приложения и административной панели.
6. Выполнить контрольные сценарии из файла [RISKI_I_TESTIROVANIE.md](RISKI_I_TESTIROVANIE.md).
7. Убедиться, что создана резервная копия и известен способ восстановления.

## 2. Локальный запуск учебного проекта

Команды выполняются из каталога проекта, где находится файл `manage.py`.

```powershell
# Активировать виртуальное окружение (если оно уже создано)
.\venv\Scripts\Activate.ps1

# Установить зависимости, если в проекте есть requirements.txt
pip install -r requirements.txt

# Применить миграции
python manage.py migrate

# Запустить локальный сервер
python manage.py runserver
```

Если виртуального окружения нет, сначала создайте его командой `python -m venv venv`. Если файл `requirements.txt` отсутствует, не выполняйте команду установки из него — зависимости нужно установить согласно фактической конфигурации проекта.

Локальный сервер предназначен для разработки и демонстрации, а не для публичного производственного размещения.

## 3. Передача пользователям

При передаче следует сообщить:
- адрес и порядок открытия приложения;
- доступные функции и известные ограничения;
- правила заполнения оценок и посещаемости;
- кому сообщать о технических проблемах;
- как часто создаются резервные копии и кто отвечает за восстановление.

Не передавайте пароли через открытые документы и не размещайте реальные персональные данные в публичном репозитории.

## 4. Сопровождение после запуска

- регистрировать обращения и ошибки;
- проверять резервные копии;
- устанавливать обновления после тестирования;
- повторно проверять основные сценарии после существенных изменений;
- документировать известные ограничения и согласованные доработки.

## 5. Лист приёмки

Перед закрытием проекта отметьте каждый пункт:

- [ ] Приложение запускается в целевой среде.
- [ ] Проверены операции со студентами и предметами.
- [ ] Проверены операции с оценками и посещаемостью.
- [ ] Результаты тестирования записаны.
- [ ] Критические ошибки устранены.
- [ ] Пользовательская памятка передана.
- [ ] Резервное копирование проверено.
- [ ] Ответственный за поддержку назначен.
- [ ] Нереализованные функции перечислены отдельно.
